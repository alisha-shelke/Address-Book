# Address Book Management System in C

**Developed by:** Alisha Shelke

## Project Overview
A contact management application developed using C programming.
It allows users to efficiently manage contact information.

## Features
- Create new contacts
- Search contacts
- Edit existing contact details
- Delete contacts
- Display all contacts
- Sort contacts

## Technologies Used
- C Programming
- Data Structures
- File Handling

## Project Structure
- main.c
- contact.c
- contact.h
- file.c
- file.h
- populate.c
- populate.h
- contacts.csv
- contacts.txt

## Description
This project demonstrates C programming concepts,
modular programming, data management, and file operations.
